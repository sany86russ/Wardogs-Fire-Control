# WARDOGS Fire Control 2.8.0 — исходники

[English](README-EN.md) · [Описание проекта и загрузка](../README.md)

Нативное приложение C++20 / Qt Widgets для артиллерии **в игре WARDOGS**. Рассчитывает горизонтальную дальность, азимут и табличную установку MIL для L81 и SPH-2. Работает с ручными координатами и локальным OCR видимых полей игры. Основа — MIT-проект [Rico217 / Ricoz217](https://github.com/Ricoz217/WarDogs_Distance_Calculator), версия `v1.4.0`; развитие и интерфейс — SoNiX.

Русский — основной язык. Переключатель **RU / EN** в шапке меняет интерфейс сразу, сохраняет выбор и не сбрасывает координаты, карту, траекторию или расчёт. Переводы встроены в EXE из `translations/*.json`.

## Работа с программой

Версия 2.8.0 проверяет стабильные релизы GitHub и по кнопке обновляет весь переносимый комплект. Механизм включает асинхронную загрузку с SHA-256, проверку манифеста, внешний помощник и откат при ошибке установки. [Инструкция](../docs/UPDATES-RU.md).

1. Подтвердите текущую карту. Стрельбище и неизвестная карта используют явный режим без высот.
2. Откройте карту клавишей **M**, выберите положение орудия через **ПКМ → Mark Coordinates** и нажмите **Alt+X**. Отправлять координаты в чат не нужно.
3. Наведите курсор на цель и нажмите **среднюю кнопку мыши**. Программа прочитает отдельные подписи X/Y около курсора и покажет дальность, направление и MIL.
4. Для SPH-2 выберите низкую или высокую траекторию. **Alt+I** необязательно записывает фактическое попадание для местной поправки; обязательных пробных выстрелов нет.
5. **Alt+C** открывает основное окно. Ручной ввод, проверка неоднозначного OCR, история, копирование расчёта, мини-карточка и прицел доступны из интерфейса.

При конфликте сочетаний интерфейс показывает фактически зарегистрированные клавиши. Сомнительная или неполная пара требует проверки. Новый непринятый захват орудия блокирует наводку по старой позиции. Перемещение орудия или смена карты очищают зависимые поправки.

## Сборка

Из корня репозитория после установки MSVC x64 и Qt 6.8+ с указанием `QT_ROOT`:

```powershell
.\Build.ps1
.\Build.ps1 -Package
```

CMake/Ninja собирают программу; обычная сборка выполняет CTest. Подготовка без запуска тестов доступна через `Build.ps1 -SkipTests`, но сочетание с обновлением `-Package` отклоняется. Подробные требования, публичная сборка и загрузка готового ZIP описаны в [корневом README](../README.md).

## Данные и ограничения

Настройки: `%LOCALAPPDATA%\WardogsFireControl\settings.ini`. Прежний профиль импортируется при первом чтении без записи в него. Допустимые локальные пакеты высот хранятся отдельно в `%LOCALAPPDATA%\WardogsFireControl\terrain-packs` и сохраняются при обновлении. Название карты выбирает пользователь; приложение не определяет его автоматически.

Community `.wdt` не входят в исходники публичного репозитория или ZIP. Их MIT-лицензия не установлена; импортировать можно только уже доступные файлы, на использование которых есть права. Для карты с высотами отсутствующий или повреждённый пакет блокирует подтверждение. Режим без высот доступен при явном выборе стрельбища или неизвестной карты. [Ручная загрузка опубликованного стороннего архива и импорт](TERRAIN_DATA_NOTICE.md) описаны отдельно. L81 не имеет подтверждённой высотной модели.

Программные тесты не удостоверяют точность попаданий в матче, разрешение издателя или видимость наложений в exclusive fullscreen. Распознавание и вычисления выполняются локально. Программа не наблюдает сам выстрел или фактическую установку прицела; наведение и огонь выполняет игрок.
