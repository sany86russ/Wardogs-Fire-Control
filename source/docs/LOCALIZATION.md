# Язык интерфейса / Interface language

## RU

Русский (**RU**) — основной язык и используется по умолчанию в новом профиле. Переключатель **RU / EN** расположен в шапке программы рядом с версией.

Нажмите **EN**, чтобы перейти на английский, или **RU**, чтобы вернуть русский. Перевод применяется сразу: перезапуск не требуется. Координаты, выбранная карта, траектория, расчёт и ожидающая проверка OCR сохраняются при смене языка. Переключение языка не подтверждает карту и не принимает распознанные координаты вместо пользователя.

Выбранный язык сохраняется в профиле `%LOCALAPPDATA%\WardogsFireControl\settings.ini` и используется при следующем запуске. Смена языка не изменяет язык WARDOGS, содержимое OCR, введённые координаты и горячие клавиши. Числа координат по-прежнему вводятся с десятичной точкой независимо от региональных настроек Windows. Обозначения оружия, **X/Y**, **MIL** и названия карт остаются узнаваемыми в обоих языках; **MIL** — шкала наведения, а не мили.

В 2.14.0 переводятся также окно **Помощники**, динамические интервалы и состояния **Выкл. / Готов / Работает** на мини-карточках. Назначенные клавиши и параметры при смене языка сохраняются.

Пользовательские руководства: [быстрый старт](QUICKSTART-RU.md), [помощники](GAME-HELPERS-RU.md), [расчёты и ограничения](CALCULATIONS-RU.md).

## EN

Russian (**RU**) is the primary language and the default for a new profile. The **RU / EN** selector is in the application header beside the version.

Select **EN** to switch to English or **RU** to return to Russian. Translation takes effect immediately; no restart is needed. Coordinates, selected map, trajectory, calculation and pending OCR review are retained when the language changes. Switching language does not confirm the map or accept recognized coordinates on the user's behalf.

The selected language is saved in `%LOCALAPPDATA%\WardogsFireControl\settings.ini` and used at the next launch. Changing the interface language does not change the language of WARDOGS, OCR content, entered coordinates or shortcuts. Coordinate numbers still use a decimal point independently of Windows regional settings. Weapon names, **X/Y**, **MIL** and map names remain recognizable in both languages; **MIL** is an aiming scale, not miles.

In 2.14.0, the **Helpers** window, dynamic timing and mini-card states **Off / Ready / Running** are translated as well. Assigned shortcuts and preferences remain unchanged when switching languages.

User guides: [quick start](QUICKSTART-EN.md), [helpers](GAME-HELPERS-EN.md), [calculations and limitations](CALCULATIONS-EN.md).
