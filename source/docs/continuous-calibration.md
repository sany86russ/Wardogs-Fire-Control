# Поправки SPH-2 по фактическому попаданию

С версии 2.5.0 используется прямой табличный расчёт и необязательный локальный режим `ContinuousCorrectionMode::local_only`. Двухточечная пристрелка больше не является входом в основной игровой сценарий. Исторический режим `platform_refinement` остаётся в математическом API и регрессионных тестах.

Для каждого наблюдения сохраняются текущая цель, траектория, предъявленные азимут/MIL и высота. Alt+I у попадания не заменяет цель. Контекст захвата неизменен; новая цель, F4, орудие или карта отменяют устаревший результат. Программа не фиксирует момент выстрела и фактические установки в игре.

Локальный режим вычисляет остаток `предъявленная команда − номинальная команда для попадания` относительно неизменного базового расчёта. Повтор с уже уточнённой наводкой оценивает тот же систематический остаток, а не добавляет его повторно. Из одной точки не строится трёхмерный наклон орудия. Учитываются только близкие наблюдения той же траектории; далёкая цель и другая траектория получают исходное решение.

Принятие наблюдения транзакционное: проверяется кандидат, затем публикуются история и поправка. В 2.5.1 вместо независимых угловых пределов проверяется геометрия: расстояние цель–попадание не больше меньшего из 400 м и 20% горизонтальной дальности. Сравнение предъявленной установки с текущим расчётом выполняется по горизонтальным векторам наведения с тем же пределом; итоговое отклонение от исходной команды ограничено двойным запасом для нелинейной таблицы. Итоговый MIL должен быть доступен. Ошибочное чтение, неполный контекст или неподдерживаемое решение сохраняют предыдущий расчёт. Первое допустимое попадание применяет полную измеренную поправку на той же цели; согласованность соседних записей определяет их вес. Независимого обрезания ±3°/±50 MIL больше нет. Пространственная область — 50 м с плавным затуханием к нулю; расстояние попадания от цели и область переноса поправки имеют разный смысл. Эти пределы являются политикой проекта, не измеренной точностью игры. Сброс удаляет необязательные поправки и возвращает исходное решение без новых пробных выстрелов. Лимит истории — 256 наблюдений.

Согласованность азимута и MIL оценивается отдельно. Для каждой компоненты используется нормированное среднее с весами согласованности: снижение общего веса не тянет все измеренные поправки к нулю. Например, два допустимых наблюдения, требующих отрицательной поправки, сохраняют отрицательную оценку между измерениями, даже если их точные величины различаются. Одиночное противоречивое наблюдение имеет меньший относительный вес, чем согласованная история. Плохая согласованность азимута не ослабляет подтверждённую поправку MIL и наоборот.

Пространственная сила отделена от согласованности. Вес каждой записи включает плавное расстояние до её цели; после нормирования сохраняется дополнительное затухание. У единственного попадания на расстоянии 25 м сила равна четверти, у повторной истории на той же точке — не больше половины. На границе 50 м и за ней влияние строго нулевое; слабый сосед у этой границы не разбавляет всю историю своим полным весом.

Регрессии включают полевую последовательность четырёх сохранённых попаданий с промахами 246 → 75 → 148 → 60 м, шум с неизменным систематическим смещением, противоречие только в одной компоненте, передачу соседней цели и крайние геометрические ограничения. Повтор полевых записей проверяет математическую оценку; он не доказывает, куда попал бы реальный снаряд с новой установкой.

Согласованность наблюдений не является вероятностью попадания. Высотная модель приблизительная; подходящих высот полигона нет. Размер цели, игровой разброс, наклон машины и точность установки прицела требуют отдельной полевой оценки.
