# Альтернативные источники координат

WARDOGS Fire Control читает видимые координаты из черновика чата и подписей около курсора. Ниже объяснено, почему текущая реализация не заменяет этот путь наблюдением за игровыми файлами или сторонним API. [Основной сценарий](COORDINATE-WORKFLOW-RESEARCH-RU.md).

## Игровые файлы и журналы

Ограниченная локальная проверка стандартных каталогов Unreal Logs/Telemetry и доступных обычных файлов не обнаружила пригодного потока выбранных X/Y. Бинарные сохранения, защищённые ресурсы и память процесса не разбирались. Игровые параметры не изменялись.

Это наблюдение для конкретного снимка среды, а не доказательство отсутствия любых координатных журналов во всех версиях игры. Без проверенных событий, задержки и соответствия новой игровой метке нельзя выдавать watcher за рабочий источник. Fire Control не следит за файлами игры.

Частные диагностические материалы, сведения об установленной машине и исходные пользовательские снимки исключены из публичного репозитория. Текущие исходники и тесты показывают реализованный путь; новые результаты сборок доступны через GitHub Actions.

## Другие возможные каналы

| Источник | Ограничение |
| --- | --- |
| Dedicated-server RCON | Требует прав сервера. В [документации проекта Warcon](https://github.com/warcon-app/warcon) нет подтверждённого клиентского потока выбранных игроком точек карты. Это стороннее описание, не официальная спецификация издателя. |
| Буфер обмена | Пользователь может явно скопировать текст координат. Сама средняя кнопка не обязана помещать X/Y в буфер; непрерывное наблюдение за ним не используется. |
| OCR чата | [Исходный проект Ricoz217](https://github.com/Ricoz217/WarDogs_Distance_Calculator) читает видимую область; его диагностический журнал не является альтернативным игровым API. |
| OCR около курсора | [ecokater](https://github.com/ecokater/wardogs-artillery) и [Melkaz](https://github.com/Melkaz/mortar-calculator) также опираются на изображение координат. Полезны поиск текста и проверка осей; чужая реализация не заменяет собственные регрессии. |

В проверенных первичных материалах не найден подтверждённый внешний канал, предоставляющий обе точки обычному локальному калькулятору. Отсутствие такого подтверждения не исключает будущего официального API.

## Требования к текущему OCR-пути

- Орудие читается из активного черновика после **Mark Coordinates**; повреждённая строка не заменяется историей чата.
- Цель и попадание читаются из отдельных X/Y-полей возле точки карты; подписи пинга, имя игрока и посторонние числа не являются координатами.
- Перед применением проверяются источник, полнота, согласие проходов и геометрия. Обрезанный знак не дополняется предполагаемой цифрой.
- Принятие орудия включает готовность средней кнопки независимо от способа ввода, видимого окна и возврата через **Alt+C**.
- Новый непринятый захват орудия блокирует новые цели по старой позиции. Смена точки или контекста отменяет устаревшее OCR-задание.
- Ошибка отображается явно; резервный путь — повторное чтение, проверка результата или ручной ввод.

Эти требования проверяются координатными фикстурами, тестами состояния и собственным нативным окном. Программные проверки не доказывают универсальное чтение всех живых игровых HUD.

## Граница интеграции

Приложение использует обычный снимок видимых пикселей, локальное распознавание, RegisterHotKey и обработку физического нажатия мыши. Оно не читает память игры, не внедряет код и не генерирует наведение или огонь. Подробности сторонних библиотек и правила издателя разобраны в [ANTICHEAT-RU.md](ANTICHEAT-RU.md).

Разрешение на игровой помощник, права на локальные данные высот и достоверность расчёта — разные вопросы. Лицензия исходников не разрешает распространять чужие игровые ресурсы; [TERRAIN_DATA_NOTICE.md](../TERRAIN_DATA_NOTICE.md) описывает исключение таких пакетов из публикации.
