# Черновик запроса об одобрении WARDOGS Fire Control

**Статус: не отправлен.** Подготовлен 7 октября 2026 года для проверки владельцем проекта; адресат и канал должны быть выбраны отдельно.

Тема: Допустимость внешнего артиллерийного калькулятора WARDOGS Fire Control

Здравствуйте. Разрабатываем неофициальный внешний калькулятор расстояния, направления и баллистической установки для WARDOGS. Хотим заранее уточнить допустимость его функций по вашим правилам.

Приложение работает отдельным Windows/Qt-процессом с обычными пользовательскими правами. Наш собственный код не читает и не меняет память или файлы игры, не внедряет DLL, не устанавливает драйверы, не генерирует игровые команды ввода и не управляет античитом. Основной режим — ручной ввод координат с локальными расчётами и историей; баллистика рассчитывается на плоском рельефе либо по допустимому пользовательскому локальному пакету высот.

По явному включению пользователем предусмотрены: чтение выбранного прямоугольника видимого экрана стандартным GDI/BitBlt с локальным OCR; заданные горячие клавиши через Windows RegisterHotKey; отдельная мини-карточка и прицел; отпускание средней кнопки через WH_MOUSE_LL только на время режима игры. Mouse hook пропускает события далее, исключает injected-ввод и не анализирует движения. По умолчанию интеграция и средняя кнопка выключены. Наш код проверяет активное окно только по заголовку/классу, без открытия процесса для определения игры.

В зависимостях Qt 6.8.3 есть общие системные API: SendInput для пользовательского touch/pen drag-and-drop и OpenProcess для резервного clipboard chain/проверки файловых блокировок. Проверенный обычный путь активации/подъёма собственных окон не использует SendInput. Полное отсутствие любых косвенных системных действий библиотек не заявляем; описание зависимостей приложим к запросу.

Просим отдельно подтвердить, допустимы ли: (1) ручной артиллерийный калькулятор; (2) OCR видимых координат; (3) отдельная карточка с расчётом поверх игры; (4) прицел; (5) hotkeys и физическая средняя кнопка только для запуска OCR; (6) расчёт по производным картам высот. Если отдельные функции недопустимы, просим указать ограничения, чтобы мы их исключили.

Одобрение использования общественного калькулятора или MIT-лицензия чужого исходного кода не рассматриваются нами как ваше разрешение. Право на поставку данных terrain выясняем отдельно у соответствующих правообладателей; спорные общественные ресурсы не должны входить в новый пакет без разрешения.

Готовы предоставить исходный код и описание системных API для проверки. До ответа не заявляем, что инструмент одобрен WARDOGS или гарантированно допускается античитом.
