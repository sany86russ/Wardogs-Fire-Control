# Откуда WARDOGS Fire Control получает координаты

Приложение использует два видимых источника: активный черновик чата для положения орудия и подписи X/Y возле курсора карты для цели или попадания. Обычный ручной ввод остаётся доступен. Подробная инструкция: [быстрый старт](QUICKSTART-RU.md).

## Положение орудия

В игре откройте карту клавишей **M**, выберите положение орудия через **ПКМ → Mark Coordinates**, затем нажмите **Alt+X**. Игровая команда помещает координаты в поле ввода чата. Приложение читает видимый черновик; отправлять сообщение не нужно.

Автопоиск ограничен верхней левой четвертью клиентской области окна. Он отделяет активную строку от истории, учитывает ширину плашки текущего канала и проверяет наличие одной полной X/Y-пары. Старые координаты из истории не заменяют отсутствующий или повреждённый черновик.

Применение без подтверждения допускается при согласии OCR-проходов, достаточной уверенности, полной геометрии знаков и подтверждённом источнике. Если условия не соблюдены, интерфейс показывает проверку или явную ошибку. Настраиваемая область и ручной ввод доступны как дополнительные пути.

## Цель и попадание

После принятия орудия **средняя кнопка мыши** читает две подписи около курсора на карте. Этот источник не зависит от обновления чата. **Alt+I** использует такие же поля для необязательного наблюдения попадания SPH-2, сохраняя выбранную цель и траекторию.

`make_map_coordinate_rects` создаёт два ограниченных участка от точки события. Исходные смещения в физических пикселях: X — `(20,-46)..(160,12)`, Y — `(-12,-120)..(140,-52)`. Два поля получаются из одного GDI-снимка объединённой области. Прямоугольники сдвигаются внутрь окна игры; курсор вне клиента или невозможная геометрия приводят к отказу.

Захват проверяет переднее окно, курсор и геометрию до и после снимка. При задержке текста допускаются два ограниченных повтора при том же контексте. Пока OCR занят, очередь содержит только последнюю ожидающую цель. Устаревшие ответы отбрасываются по эпохе ввода. Повторный выбор той же точки допустим: актуальность определяется событием и источником, а не обязательным изменением чисел.

В X-поле требуется полная подпись X, в Y-поле — Y. Курсор, граница сетки, пинг и другие соседние элементы отделяются по геометрии строки; обрезанные цифры не восстанавливаются догадками. Во время нового чтения или неразрешённой ошибки старая наводка скрыта.

## Источники реализации

Основа приложения — [Rico217 / Ricoz217, WarDogs Distance Calculator](https://github.com/Ricoz217/WarDogs_Distance_Calculator), MIT, версия `v1.4.0`. Сценарий развивался по наблюдаемому интерфейсу игры и предоставленным примерам. Публичный репозиторий содержит текущие исходники и обезличенные OCR-регрессии; исходные пользовательские снимки и частные исторические диагностические квитанции не публикуются.

Независимые открытые проекты помогают сопоставить подходы:

- [ecokater / wardogs-artillery](https://github.com/ecokater/wardogs-artillery) ищет белые координаты рядом с курсором, связывает ось с числом и ограничивает кандидатов геометрией текста.
- [Melkaz / mortar-calculator](https://github.com/Melkaz/mortar-calculator) описывает локальное чтение подписанных координат по образцам шрифта.
- [Apollyon / wardogs-calculator](https://github.com/apollyon-sys/wardogs-calculator) предоставляет отдельный веб-калькулятор и документы о происхождении игровых данных.

Описание чужого инструмента не подтверждает работу текущего Fire Control на любом HUD и не даёт разрешения на игровые автоматизации. Здесь используются только видимые координаты; движение прицела, огонь и другие игровые действия не автоматизируются.

## Проверки и ограничения

OCR-тесты используют обрезанные координатные поля и сцены с закрытым личным текстом. Собственное нативное окно проверяет Windows-захват, клавиши и цепочку передачи результата. Эти тесты не являются живым матчем WARDOGS.

Поддержка каждого сочетания разрешения, масштаба HUD, языка игры, мониторов и оконного режима требует отдельных снимков с известной правильной парой X/Y. Фиксированные смещения и ограниченный повтор с масштабированием не означают универсальный поиск текста по всему интерфейсу.

Приложение не подключается к игровым журналам или закрытому API. [Проверка альтернативных источников](COORDINATE-SOURCES-INVESTIGATION-RU.md) объясняет этот выбор. [Взаимодействие с игрой и античит](ANTICHEAT-RU.md) описывает системные API и границы: одобрение издателя и отсутствие санкций не установлены.
