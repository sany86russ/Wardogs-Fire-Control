# v2.13.2

## Русский

- Удалено автоматическое чтение HUD прицела SPH-2 и фоновый захват окна игры через Windows Graphics Capture. Калькулятор больше не запускает этот захват, вызывавший мигание системной рамки окна игры.
- Из мини-карточки удалены статус распознавания прицела и цветная рамка сравнения с наводкой.
- Удалена подписка на выстрелы левой кнопкой. Расчёты L81/SPH-2, учёт высот, OCR координат по горячим клавишам и средней кнопке, поправки Alt+I сохранены.
- Настройки, карты, история точек и логи совместимы с предыдущей версией.

## English

- Removed automatic SPH-2 sight HUD reading and background Windows Graphics Capture of the game window. The calculator no longer starts this capture, which caused the system capture border to flash.
- Removed the mini-card sight recognition status and coloured sight-agreement border.
- Removed the subscription to left-button fire intentions. L81/SPH-2 calculations, terrain, hotkey/middle-button coordinate OCR and Alt+I corrections are preserved.
- Settings, maps, point history and logs remain compatible with the previous version.
