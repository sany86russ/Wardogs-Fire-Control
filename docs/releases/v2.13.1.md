# WARDOGS Fire Control 2.13.1

## Русский

Исправление чтения оптического HUD SPH-2 и диагностики мини-карточки.

- HUD получает свежий кадр конкретного окна через Windows Graphics Capture. Повторно выданный старый client-DC кадр больше не используется как показание прицела. Время кадра композитора, размеры и принадлежность окна проверяются для каждого запроса.
- Чтение опирается на реальные штрихи прицела, обе боковые шкалы RNG/MIL и внутренний компас. Уточнены положения толстых рисок и выделение полных цифр на сложном фоне; обрезанные и противоречивые подписи остаются отказом.
- Сначала читаются реальные строки вокруг указателя на обеих шкалах. Дополнительные строки не запускают каскад повторных попыток. Свежий полный результат получает ограниченный повторный опрос; возраст показания по-прежнему ограничен одной секундой.
- Поддержаны точные русские подписи состояния стабилизации при наличии соответствующего пакета Windows OCR. Нечитаемое состояние остаётся неизвестным.
- Мини-карточка объясняет отсутствие подтверждённого HUD. Расчёт команды продолжает работать независимо от сравнения с игровым прицелом.
- Журнал сообщает конкретную причину отказа, этап захвата и распознавания, время обработки и счётчики результатов. Обычная работа не сохраняет снимки игры или сырой OCR-текст.
- Связь прицела с нажатием использует исходное время сообщения Windows, отдельно от задержки callback и OCR. Неопределённое время не подтверждает прицел перед нажатием.
- Добавлены регрессионные проверки геометрии, полных цифр, конфликтов, свежести и часов ввода, а также отдельная проверка консольного читателя на приватных кадрах с закреплёнными SHA256.

Проверки сохранённых кадров подтверждают только наблюдавшиеся ракурсы и разрешение. Изолированная проверка интерфейса не заменяет игровой сеанс. Зелёная рамка означает согласованность команды и показания в пределах погрешности; гарантии попадания и проверка физического выстрела не заявляются. Таблицы и чтение координат карты сохраняются.

## English

Fixes SPH-2 optical HUD reading and mini-card diagnostics.

- HUD capture obtains a fresh frame of the selected window through Windows Graphics Capture. A cached client-DC image can no longer supply sight evidence. Each request validates the compositor timestamp, window identity and physical geometry.
- Reading uses actual reticle strokes, both RNG/MIL ladders and the inner compass. Thick tick localisation and complete glyph isolation handle difficult backgrounds; clipped or conflicting labels still cause refusal.
- Independently measured rows around the pointer are read first on both ladders. Additional rows do not trigger retry cascades. Fresh complete readings receive a bounded retry interval, retaining the one-second age limit.
- Exact Russian stabilization captions are supported when the corresponding Windows OCR language is installed. Unreadable stabilization remains unknown.
- The mini card explains unavailable HUD evidence. Command calculation continues independently of the actual-sight comparison.
- Diagnostics record named refusals, capture/recognition stages, processing time and outcome counters. Normal operation saves neither game screenshots nor raw OCR text.
- Pre-press sight association uses the original Windows message time independently of callback and OCR delays. Unavailable input timing cannot establish a pre-press sight.
- Regression coverage includes geometry, complete digits, conflicts, freshness and input clocks. Native console qualification uses private, hash-pinned frames.

Retained-frame checks cover only the observed poses and resolution. Isolated UI checks do not replace a game session. A green border means compatibility between the command and observed interval; it does not guarantee a hit or authenticate a physical shot. Ballistic tables and map-coordinate reading are preserved.
